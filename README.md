# DOOM 3D — Raycaster

브라우저에서 바로 플레이하는 싱글파일 3D 둠 스타일 슈터. 외부 의존성 없음.

- 🎮 플레이: https://mgmudkip.github.io/doom3d/
- 📦 리포: https://github.com/MgMudkip/doom3d

## 실행 방법

별도 빌드 없이 `index.html` 하나면 동작한다.

```bash
# 방법 1: 파일 직접 열기
xdg-open index.html

# 방법 2: 로컬 서버
python3 -m http.server 8000
# → http://localhost:8000/index.html
```

Chrome/Edge 권장. 소리를 켜면 효과음 + BGM이 나온다. (브라우저 정책상 첫 클릭 후 오디오 활성화)

## 게임 목표

악마 12마리가 점령한 전초기지를 돌파하고 초록색 **EXIT 문**에 도달하면 클리어.

## 조작법

| 키 | 동작 |
|---|---|
| `WASD` | 이동 (W/S 전후진, A/D 스트레이프) |
| 마우스 | 조준 (클릭 = 포인터락) |
| 클릭 / 스페이스 | 발사 |
| `1 / 2 / 3` | 권총 / 산탄총 / 체인건 |
| `E` | 문 열기 / EXIT 사용 |
| `SHIFT` | 달리기 |
| `M` | 미니맵 토글 |
| `P` | 일시정지 |
| `← / →` | 회전, `↑ / ↓` | 전후진 |

모바일: 좌측 조이스틱 이동, 우측 드래그 조준, FIRE/USE 버튼.

## 구성 요소

- **엔진**: 480-ray DDA 레이캐스팅, 어안 보정, 8종 절차적 벽 텍스처, 거리·측면 음영, 화면 흔들림, 머즐라이트
- **맵**: 24×24 (`RAW_MAP`), 자동문, 용암/테크/오컬트 구역, 미니맵(`M`)
- **적**: 임프(원거리 화염탄) / 핑크데몬(빠른 근접) / 카코데몬(고체력) — 추적 AI, 시야(Line-of-Sight) 판정, 고통·사망 모션, 체력바
- **무기**: 권총(정밀) / 산탄총(7펠릿 근접 폭발) / 체인건(고속 연사)
- **아이템**: 메드킷 +25, 탄약 +20, 아머 +50, 산탄총·체인건 픽업
- **HUD**: 탄약 / 체력 / 아머 / 킬수 / 상태 표정 + 데미지·회복 플래시
- **오디오**: WebAudio 절차적 생성 (발사음·피격·픽업·문·성장 + 베이스 BGM 루프)

## 파일 구조

```text
doom3d/

```

`index.html` 하나에 전부 들어 있어 GitHub Pages가 그대로 서빙한다.
